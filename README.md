# 永遠之暗悲惶殲滅戰 練習場（FF14 7.3）

3D 機制練習場：你只控制自己，其他 7 人是照攻略走位的 NPC；站錯會立刻停下並用中文說明原因。
每個機制可以單選，也能跑全程。

**操作**：WASD 移動、空白鍵跳躍、拖曳轉視角、滾輪縮放、Enter 開始／重來。

攻略依據：B 站子言姐姐〈【FF14】7.3攻略 永远之暗悲惶歼灭战+设定考据〉（BV1xWatzpEdU）及其「站位總結」。

## 機制（全程順序）

| 段落 | 內容 |
| --- | --- |
| 青之衝擊 | 兩次 90° 扇形死刑：MT 左上角吃第一下、ST 右上角吃第二下 |
| 死之恐懼 | 8 灘黑泥（兩種配置），站在自己黑泥外側，黑手直線朝場外 |
| 暗之死腕 | 先站中間（兩側先打），再到「沒發光的手」那側 |
| 死亡警告 | 雙 T 去黑翼側、6 人去白翼側，躲手的直線後黑暗一擊分散；黑泥消失前不進中間 |
| 青魂 | 記住儲存的是「內」還是「外」，接二重波（雙 T 四人分攤）或四重波（兩人分攤） |
| 青魂第二輪 | 存 → 死之恐懼 → 引導之翼（原地放圓、黑手直線出現再閃）→ 青之衝擊 → 分攤 |
| 大十字 | 縮成圓形、四區兩兩分組；黃圈、旋轉直線、踩塔／放圓形兩輪、斜角躲十字、中子環 |

| 青之連魂 | 存 4 個（內內外外的旋轉），靈魂輪轉後從最下方的圖示開始依序放，最後一下同時分攤 |
| 青之環波 | 先進先變大的角落光圈，躲巨手橫掃的那排，再進中間光圈 → 青魂分攤 |
| 群體恐慌 | 2 人塔（東西兩側）＋死亡警告 → 3 人塔＋青之衝擊（MT）→ 換塔＋青之衝擊（ST）→ 暗之死腕 |
| 後半 | 青之連魂、死之恐懼、青之環波、死亡警告＋暗之死腕、大十字、永遠之暗（狂暴） |

## 站位

- 場標（影片「场地标点」）：1、2 在北邊、3、4 在其下方；A 西、C 在 A 內側；B 東、D 在 B 內側。
- 分攤：安全在內 → 數字點（四重：MT/D1=1、ST/D2=2、H1/D3=3、H2/D4=4；二重：左右兩組在 3／4 附近）；
  安全在外 → 字母點（四重：MT/D1=A、ST/D2=B、H1/D3=C、H2/D4=D；二重：A／C 之間、B／D 之間）。
- 大十字分區：MT/D1 左上、ST/D2 右上、H1/D3 左下、H2/D4 右下。

## 推估與簡化

- 範圍大小與讀條時間都是推估值；王的扇形分攤半角 9°、青之衝擊 90°。
- 青之連魂的圓形／環形以王為圓心（圓形 → 站外、環形 → 站內）。
- 青之環波：只做「角落光圈 → 中間光圈」兩段，巨手隨機掃第一排或中間排。
- 群體恐慌的死亡警告只做中間直線與黑泥，沒有做手的直線。
- 小怪階段的進度條固定在時間內打完；單人異空間（打小怪、跳平台）不是走位機制，略過。

## 專案結構

```
index.html            HUD／設定面板骨架
css/style.css
three.min.js          Three.js r152（本機優先，失敗再試 CDN）
js/boot.js            載入 Three.js，再依 APP_FILES 順序載入
js/core/constants.js  職能、場標、幾何判定
js/core/scene.js      渲染器、相機、長方形地板、王（翅膀、巨手、胸前輪盤）
js/core/visuals.js    圓／環／扇／矩形／直線、黑手模型、特效
js/core/members.js    8 名隊員
js/core/engine.js     設定、時間軸引擎、成功／失敗
js/core/necron.js     共用機制：儲存攻擊、分攤扇形、青之衝擊、暗之死腕、死亡警告、死之恐懼
js/mechanics/*.js     p1、大十字、小怪、p2
js/steps.js           全程順序
js/input.js, js/main.js
```

測試掛鉤：`window.__autopilot = true`（玩家照 NPC 計畫走）、`window.__substeps = 4`（加速）、
`window.__force_<設定 id>`（例如 `__force_soulVar = 'in'`、`__force_orb = 'TL'`、`__force_band = 'mid'`）。
